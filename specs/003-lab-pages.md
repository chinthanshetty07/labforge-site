# Spec 003: Lab detail pages

## Acceptance criteria
- **AC-3.1** One page per lab in `src/data/labs.json`, at `/labs/<slug>/`.
- **AC-3.2** Each page shows the lab title as its `h1`, the duration, the level and the list of skills.
- **AC-3.3** Each page has `Course` JSON-LD with name, description and provider = LabForge.
- **AC-3.4** Each page links back to the home page and to the demo form.
